┌─────────────────────────────────────────────────────┐
│  1️⃣  ورود به وب‌سایت                                │
└─────────────────────────────────────────────────────┘

   🌐 آدرس: http://localhost:3000

   📧 ایمیل و پسورد: همان مقادیری که هنگام ساخت Admin تعیین کرده‌ای
   👑 نقش: Admin

┌─────────────────────────────────────────────────────┐
│  2️⃣  استفاده از بات تلگرام                          │
└─────────────────────────────────────────────────────┘

   روش ساده:
   ./start-telegram-bot.sh

   یا:
   export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN"
   export TELEGRAM_CHAT_ID="YOUR_CHAT_ID"
   export PROXY_PORT=10808
   node scripts/telegram-bot.js

   دستورات در تلگرام (@ChefarashBot):
   /status  - داشبورد کامل
   /vulns   - آسیب‌پذیری‌ها
   /scans   - اسکن‌های اخیر
   /programs - برنامه‌های فعال
   /help    - راهنما

┌─────────────────────────────────────────────────────┐
│  3️⃣  مدیریت Docker                                   │
└─────────────────────────────────────────────────────┘

   مشاهده وضعیت:
   docker ps

   روشن کردن:
   docker compose -f docker-compose.dev.yml up -d

   خاموش کردن:
   docker compose -f docker-compose.dev.yml down

   ری‌استارت:
   docker compose -f docker-compose.dev.yml restart

   لاگ‌ها:
   docker logs bb-backend -f
   docker logs bb-frontend -f

┌─────────────────────────────────────────────────────┐
│  6️⃣  عیب‌یابی                                        │
└─────────────────────────────────────────────────────┘

   سایت باز نمیشه؟
   → docker logs bb-frontend -f

   لاگین کار نمی‌کنه؟
   → docker logs bb-backend -f
   → docker restart bb-backend

   بات وصل نمیشه؟
   → چک کن پروکسی روی پورت 10808 فعاله
   → ss -tlnp | grep 10808

   Docker مشکل داره؟
   → docker compose -f docker-compose.dev.yml down
   → docker compose -f docker-compose.dev.yml up -d
